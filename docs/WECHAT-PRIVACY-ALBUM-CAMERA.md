# 微信小程序 errno:112 排查（相册 / 拍照）

## 错误表现

录入课时点击 **拍照** 或 **相册** 时，提示：

> 公众平台未声明相册/摄像头  
> 请到微信公众平台的用户隐私保护指引里勾选「选中的照片或视频」和「摄像头」…

或接口返回 `errno: 112`、`scope is not declared in the privacy agreement`。

含义：当前小程序版本在《用户隐私保护指引》中**未声明**与 `wx.chooseImage` / 摄像头相关的隐私类型。仅在小程序内点「同意」**不能**替代公众平台配置。

## 必须勾选的项（名称要一致）

登录 [微信公众平台](https://mp.weixin.qq.com) → **设置** → **服务内容声明** → **用户隐私保护指引** → **更新**：

在「开发者处理的信息」中勾选（用途说明示例见下）：

| 处理的信息（须勾选） | 对应接口 | 后台 privacy_key |
|---------------------|----------|------------------|
| **收集你选中的照片或视频信息** | `wx.chooseImage`（相册选图 + 拍照，都算这一项） | Album |

建议用途说明（可按机构文案微调）：

- **选中的照片或视频**：用于拍摄或选择课堂照片，上传至课时记录留档。

### 不要勾选「访问你的摄像头」

「访问你的摄像头」对应的是 `wx.authorize({scope:'scope.camera'})`、`<camera>` 组件、`wx.createVKSession` 等**直接调用摄像头**的接口。本项目拍照走的是 `wx.chooseImage`（系统相机），**没有**调用这些接口，所以勾选后审核会报：

> 【访问你的摄像头接口】说明内容不符合接口使用场景

同理，没有调用 `wx.saveImageToPhotosAlbum` 就不要勾选「使用你的相册（仅写入）权限」。
`manifest.json` 里也不要再写 `permission.scope.camera`。

保存后状态须为 **审核通过**（「审核中」「已驳回」时接口仍禁用）。

## 仍报 112 的常见原因

与手机号类似，见 [WECHAT-PRIVACY-112.md](./WECHAT-PRIVACY-112.md) 中「只改现网、预览用开发版」等章节，同样适用于相册/摄像头：

1. **隐私指引未审核通过** — 通过后等待约 30 分钟～1 小时再测。  
2. **只改了设置页，预览版未同步** — **管理** → **版本管理** → **提交审核**，在提审流程里按提示更新**开发版**隐私指引并勾选 Album、Camera。  
3. **上传的代码未包含选图接口** — 无需在 `manifest.json` 声明（`requiredPrivateInfos` 只支持 `getLocation`、`chooseAddress` 等位置/地址类接口，写 `chooseImage` 会导致预览报错）。微信会根据代码里实际调用 `wx.chooseImage` 自动在后台列出「选中的照片或视频」必填项。  
4. **AppID 不一致** — 须为 `wx990725d3b911a978`（与 `src/manifest.json` 一致）。  
5. **本地缓存** — 删除小程序 → 重新预览/打开；开发者工具清授权。

## 建议自检顺序

1. 公众平台 → 用户隐私保护指引 → 勾选 **选中的照片或视频** + **摄像头** → **审核通过**  
2. 上传含 `chooseImage` 的最新小程序代码 → 提交审核流程中确认隐私项一致  
3. 等待 ≥30 分钟  
4. 删小程序 + 真机预览 → 录入课时 → 拍照/相册  

## 通过后预期

点击拍照或相册可正常唤起系统界面；若仅未在小程序内同意隐私，会先出现「隐私保护提示」，点 **同意** 后再选图。
