# 微信小程序 errno:112 排查（getPhoneNumber）

## 错误

```
getPhoneNumber:fail api scope is not declared in the privacy agreement
errno: 112
```

含义：当前运行的**小程序版本**在《用户隐私保护指引》中**未声明**与 `getPhoneNumber` 对应的隐私类型 **「收集你的手机号」**。与业务代码、后端无关。

## 必须勾选的项（名称要一致）

在 [微信公众平台](https://mp.weixin.qq.com) → **设置** → **服务内容声明** → **用户隐私保护指引** → **更新**：

在「开发者处理的信息」中，必须勾选平台列出的：

| 处理的信息（须勾选） | 对应接口/组件 |
|---------------------|---------------|
| **收集你的手机号** | `<button open-type="getPhoneNumber">` |

仅写用途说明、只填自定义文案、或只勾选其它类型（如用户信息），**不能**替代这一项。

## 仍报 112 的常见原因

### 1. 隐私指引未审核通过

- 保存后状态须为 **审核通过**，「审核中」「已驳回」时接口仍禁用。
- 通过后等待 **5 分钟～1 小时** 再测（社区反馈偶有延迟）。

### 2. 只改了「现网」指引，预览用的是「开发版」

预览/开发版使用的隐私协议，可能与「设置」里单独更新的现网指引**不是同一份**。

请同时检查：

1. **管理** → **版本管理** → **提交审核**（即使暂不发布，也可走提交流程里的隐私检查）
2. 若提审页提示「隐私协议与代码调用不一致」，在**该页**按提示更新指引并勾选 **收集你的手机号**
3. 从未发布过的小程序：往往要在**首次提审**时确认/更新开发版隐私协议，仅改设置页可能预览不生效

### 3. 代码里用了 getPhoneNumber，但提审未同步隐私

微信会根据**提交审核的版本**检测是否调用了 `getPhoneNumber`。若从未上传过含该按钮的版本，后台「必填项」可能未出现手机号项。

建议：上传一版含登录页 `getPhoneNumber` 的代码走**提交审核**（可先选「仅审核不发布」若平台支持），在提审流程中完成隐私指引确认。

### 4. AppID 不一致

开发者工具 / 预览使用的 AppID 须为 **`wx990725d3b911a978`**（与 `src/manifest.json` 一致）。

### 5. 本地缓存

- 手机：删除小程序 → 重新扫码预览  
- 开发者工具：**清缓存** → **清除授权数据** → 重启工具  

## 建议自检顺序

1. 公众平台 → 用户隐私保护指引 → 确认已勾选 **收集你的手机号** → 状态 **审核通过**  
2. 开发 → 开发管理 → **接口设置** → 手机号快速验证已开通  
3. 版本管理 → 提交审核 → 按页面提示更新**开发版**隐私协议  
4. 等待 ≥30 分钟（仍不行可等 1 小时）  
5. 删小程序 + 清授权 + 真机预览再点「微信手机号登录」  

## 通过后预期

vConsole 中 `getPhoneNumber` 的 `errMsg` 应为 `getPhoneNumber:ok`，且 `detail.code` 有值；随后才会请求后端 `/auth/wechat/miniprogram/login`。
